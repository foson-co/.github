# Foson Engineering

We build AI-first SaaS for small and medium businesses — and open-source the infrastructure we build them on. Company site: [foson.co](https://foson.co) (中文).

## Open source

### [Arkite UI](https://github.com/foson-co/arkite-ui)

Production-ready **React components for multi-tenant SaaS admin panels** — data tables with a server-side mode, admin layouts with mobile bottom navigation, filter bars, OTP inputs. Built on **Tailwind CSS v4 + Radix UI + TypeScript**.

- 70 components · 1,200+ tests · WCAG AA enforced in CI, not by policy
- Dogfooded by nine production SaaS products before every release
- **AI-ready**: machine-readable docs at [ui.foson.co/llms.txt](https://ui.foson.co/llms.txt) and inside the npm package — your coding agent imports the right component on the first try
